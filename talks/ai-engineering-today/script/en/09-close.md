# Three things to remember

{#takeaways}Three things to take with you. {#take-words}One, the words. Context is everything the model sees. An agent is a model using tools in a loop. A workflow is a path you wrote. {#take-job}Two, the job. We direct and we verify. {#take-enforce}Three, the rules. A rule that really matters belongs in a hook, not a prompt.

{#try-this}One thing to try this week. Pick one real task. Before you prompt, write three lines: the goal, the limits, and the check that proves it's done. Then give the agent that check.

{#callback}English may be the hottest new programming language. The engineering is still ours.

# Context {tag: Context}

Context engineering means choosing what the AI sees: instructions, tools, files, and history. {#workbench}Think of a workbench: you lay out only what the job needs. {#quote}Anthropic calls it the natural progression of prompt engineering.

{#skill}A skill is a recipe. {#agent}An agent is the AI, using tools to follow it. {#harness}Claude Code is the harness: the workspace, tools and permissions. {#workflow}A dynamic workflow runs agents step by step, and checks each step.

{#loop}A loop means try, check, adjust. In a test I set up, {#failed}one command failed three times in a row. {#loop-guard}A hook said stop, {#stopped}and the agent stopped. {#hooks}Hooks are small checks on every command and edit. {#handoff}A handoff writes down what's done and what's next, for the next session.
